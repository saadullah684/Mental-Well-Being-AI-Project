# Mental Well-Being AI

This is my Project developed using Python, Streamlit, and Machine Learning.

The project is an AI-based Mental Health Assessment System designed to help university students identify early signs of stress and anxiety.

# Features
- User Authentication (Login/Signup)
- AI-based Stress & Anxiety Prediction  
- Psychological Scales (PSS & GAD-7)  
- Personalized Recommendations  
- MongoDB Database Integration  

# Technologies Used
Python, Streamlit, Machine Learning, MongoDB, Scikit-learn

# Purpose
This project helps students identify early signs of stress and anxiety using AI-based analysis. It is not a replacement for medical professionals but an awareness tool.
